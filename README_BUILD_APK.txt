CREATOR STUDIO — ANDROID APP PROJECT

This ZIP is an Android Studio project, not a finished APK file.

BUILD YOUR APK:
1. Install Android Studio on a computer.
2. Extract this ZIP.
3. In Android Studio choose File > Open and select the extracted CreatorStudio folder.
4. Wait for Gradle sync. Install Android SDK Platform 35 if Android Studio asks.
5. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Android Studio will show a notification with a link to the generated APK.
7. Copy the APK to your Android phone and open it. If Android asks, allow installing apps from that source.

WHAT IS INCLUDED:
- Android app shell named Creator Studio
- Your existing sign-up/login prototype embedded locally
- App icon/launcher entry handled by Android's default icon until you add a custom one
- Works offline for the included prototype screens

IMPORTANT:
- This is a prototype, not a production-ready service.
- Login details are stored in the app's local browser storage and are NOT secure.
- Do not use a real or reused password.
- AI image/video generation, secure accounts, cloud sync, payments, password reset and email verification are not connected yet.
- Do not publish this version or collect real customer information until secure authentication and backend services are added.
